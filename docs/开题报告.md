# 面向自由电子激光诊断系统的在线数据采集与束流异常检测方法研究

## 一、选题背景与意义

### 1.1 自由电子激光与高重频诊断数据挑战

自由电子激光（Free Electron Laser, FEL）是第四代同步辐射光源，利用相对论电子束在周期磁场（波荡器）中受激辐射产生高亮度、飞秒级、空间相干的 X 射线脉冲，是研究物质超快结构与动力学过程的核心工具。

我国正在建设的硬 X 射线自由电子激光装置 SHINE（Shanghai HIgh repetitioN rate XFEL and Extreme light facility）由上海科技大学、中国科学院上海高等研究院等承担，采用 8 GeV 连续波（CW）超导直线加速器，最高重复频率达 1 MHz，覆盖 0.4–25 keV 光子能量，规划 3 条波荡器线、3 条光束线与首批 10 个实验站[1,2]。该装置注入器已于 2024 年底完成设计指标的束流调试，L1/BC1 段于 2025 年底完成调试，计划 2026 年首次出光[2]。建成后 SHINE 将成为国际上重复频率最高的 XFEL 之一（与 LCLS-II 的 1 MHz 相当，远高于欧洲 XFEL 的 4.5 MHz 束团内重频、27 kHz 平均重频）[3]。

高重复频率与连续波运行在带来性能飞跃的同时，也带来前所未有的**数据与运维挑战**：

1. **诊断信号海量且多维**。束流位置监测器（BPM）、束流电荷监测器（BCM）、能量监测器、发射度监测器、RF 相位/幅度、束损监测器（BLM）等设备以 kHz 至 MHz 级持续产生多通道时序数据，一台装置需监控的变量可达数十万量级（LCLS 约 20 万变量）[4]；
2. **异常稀疏且多样**。束流丢失、轨道漂移、横向不稳定、RF 相位跳变等异常发生频率低、形态各异，且出现时可能导致实验数据作废甚至设备损伤，人工无法实时盯守全部信号；
3. **标注极度稀缺**。真实运行中绝大多数数据无标签，"异常"定义本身依赖物理经验，难以构造大规模监督学习样本。

### 1.2 研究意义

**理论意义**：将无监督时序异常检测方法（重建类、关联类）引入自由电子激光诊断系统，针对"多通道、强相关、异常稀疏"的束流时序数据，研究关联建模与异常判定的有效准则，丰富无监督异常检测在复杂工程系统中的应用理论。

**工程意义**：面向 SHINE 这类国产 MHz 级装置，构建"数据采集 → 在线处理 → 异常告警"的原型系统，为诊断系统的自动化运维与闭环保护提供技术支撑，降低对人工经验的依赖，提升装置运行效率与可靠性。

## 二、国内外研究现状

### 2.1 加速器控制系统与诊断系统

加速器领域的主流控制系统是 EPICS（Experimental Physics and Industrial Control System），采用分布式 IOC（Input/Output Controller）+ Channel Access/pvAccess 协议，已被 LCLS、SNS、国内上海光源等广泛采用，为诊断信号的采集与分发提供了成熟基础设施[5]。欧洲 XFEL 则基于 Karabo 框架实现探测器控制与数据流管理，其单台 AGIPD 探测器原始数据率高达 10–15 GB/s[6]。这些系统解决了"采得到、传得出"的问题，但**诊断数据的"看得懂、判得准"仍主要依赖阈值告警与人工判断**。

### 2.2 时序异常检测方法研究进展

时序异常检测方法可分为三类：

1. **传统统计/机器学习方法**：孤立森林（Isolation Forest）[7]、单类支持向量机（OC-SVM）[8]、基于极值理论的 SPOT 流式检测[9]等。这类方法简单高效，但对多变量时间依赖与通道关联的建模能力有限，高维场景下误报率较高。
2. **基于重构的深度学习方法**：自编码器（AE）、LSTM-AE、OmniAnomaly[10]、USAD[11]等，通过学习"正常工况"的低维表征并以重构误差作为异常得分，是无监督时序异常检测的主流范式。
3. **基于关联/注意力的方法**：Anomaly Transformer[12] 提出"关联差异"（Association Discrepancy）准则，利用自注意力权重分布区分正常与异常点，在 6 个基准数据集上达到当时最优；TranAD[13]、DCdetector 等进一步引入对抗训练与对比学习。这类方法显式建模多通道间的时间关联，与束流诊断数据的物理结构高度契合。

Schmidl 等[14]与 Blázquez-García 等[15]的综述系统比较了上述方法，指出**方法性能高度依赖数据特性，多变量、强相关、异常稀疏场景下关联类方法通常更具优势**。

### 2.3 加速器领域的机器学习异常检测

机器学习用于加速器异常检测是近年兴起的方向，已有若干代表性工作：

- **SLAC/LCLS**：Humble 等提出 ResVAE（Resilient VAE），在训练数据含异常的前提下利用逐样本、逐特征异常概率实现鲁棒无监督检测，并基于 LCLS 的逐发（shot-to-shot）BPM 数据验证了方法有效性[16]；此外还有面向 RF 站故障的"基于束流的故障识别"方法[17]。
- **Jefferson Lab/CEBAF**：Chen 等采用 LSTM-AE 对轨道锁（orbit lock）系统的监测数据进行异常检测，对已知故障的识别率达到 68.6%–89.3%[18]。
- **APS**：Edelen 等探索了自编码器重构分析用于储存环磁铁故障预测[19]。

### 2.4 研究现状小结与存在的空白

综合来看，现有工作存在以下不足，构成本课题的切入点：

1. **装置覆盖面有限**：上述工作集中于 LCLS、CEBAF、APS 等国外装置，面向 SHINE 这类国产 MHz 级连续波装置的公开研究尚少；
2. **信号单一、缺乏关联建模**：多数工作聚焦单一子系统（BPM 或 RF），未能充分利用多通道诊断信号间的物理关联；Anomaly Transformer 等关联类方法在束流诊断数据上的适用性尚未被系统评估；
3. **"在线"闭环不完整**：现有研究多为离线分析，缺乏"采集 → 在线推理 → 告警"的一体化系统设计与延迟/吞吐评估。

## 三、研究目标、内容与关键问题

### 3.1 研究目标

面向自由电子激光诊断系统，研究并实现一个**多通道束流时序数据的无监督异常检测方法**，并构建**在线数据采集与异常告警原型系统**，在仿真与公开数据上验证方法有效性，为 SHINE 类装置的诊断自动化提供方法与系统支撑。

### 3.2 研究内容

1. **束流诊断数据的建模与仿真生成**：建立"潜在物理因子 → 线性混合 → 观测通道"的仿真模型，生成具有真实通道相关性的多通道诊断时序，并注入束损尖峰、轨道漂移、横向振荡、RF 阶跃、噪声增大等多类异常，产出逐点、逐通道、逐类型标签（本课题已实现原型 `feldiag` 生成器）。
2. **无监督异常检测方法研究**：实现并对比三类方法——传统基线（孤立森林、PCA 重构）、重建类（AE、LSTM-VAE）、关联类（Anomaly Transformer、TranAD），评估其在束流诊断数据上的检测精度、逐类召回与抗误报能力。
3. **在线采集与处理系统原型**：基于 EPICS/流式缓冲构建"采集 → 滑动窗口在线推理 → 异常告警"的原型链路，评估在线推理的延迟与吞吐，验证方法可部署性。
4. **实验评估与对比分析**：在仿真数据与公开时序异常检测基准（SMD、PSM 等）上进行跨域验证，系统分析各方法在不同异常类型、不同信噪比下的表现。

### 3.3 拟解决的关键问题

1. **多通道关联的有效建模**：如何利用束流诊断通道间的物理关联，在无监督条件下构造可区分正常与异常的判定准则；
2. **稀疏异常下的无监督训练**：如何在标注稀缺、训练集可能含异常的条件下训练稳定的检测模型；
3. **在线实时性与精度的权衡**：如何在保证检测精度的同时满足在线推理的低延迟要求。

## 四、研究方法与技术路线

### 4.1 总体技术路线

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  数据源       │ → │  采集层       │ → │  在线检测层    │ → │  输出/告警     │
│  BPM/BCM/EM  │   │  EPICS IOC +  │   │  滑动窗口 +    │   │  异常分数曲线 │
│  RF/BLM/定时 │   │  pvAccess     │   │  GPU 推理      │   │  + 告警 + 归档 │
└──────────────┘   └──────────────┘   └──────────────┘   └──────────────┘
        ↑ 仿真数据（feldiag 生成器）          ↑ 模型（AE/LSTM-VAE/Anomaly Transformer）
```

### 4.2 数据仿真与构建

采用已实现的 `feldiag` 生成器：以束流能量、电荷、横向位置、RF 相位/幅度为潜在因子，经线性混合得到 12 个观测通道，注入 5 类异常并输出分层标签（`label`/`type_label`/`channel_label`）。同时引入 SMD、PSM 等公开遥测时序数据集做跨域验证。

### 4.3 异常检测模型

- **基线**：滑动均值+阈值、孤立森林、PCA 重构误差；
- **重建类**：AE → LSTM-VAE，以重构误差为异常得分；
- **关联类**：Anomaly Transformer（关联差异准则）、TranAD；
- 评价指标：逐点 Precision/Recall/F1、AUC，逐类 F1（利用 `type_label`），以及在线延迟/吞吐。

### 4.4 在线系统原型

基于 EPICS 模拟 IOC（或 ZeroMQ 采集节点）驱动数据流，经滑动时间窗口输入 ONNX/TensorRT 优化的推理模型，输出异常分数并触发告警，验证端到端延迟与吞吐。

## 五、创新点

1. **面向束流诊断数据的多通道关联异常检测**：将 Anomaly Transformer 等关联类方法与束流诊断数据的物理关联结构结合，系统评估其在加速器场景下的适用性（区别于现有单信号方法）；
2. **物理可解释的仿真数据生成框架**：以"潜在因子 → 线性混合"显式建模通道相关性，并产出逐类型、逐通道标签，为异常检测提供可控、可复现的评估基准；
3. **"采集—在线推理—告警"一体化原型**：打通从数据采集到在线异常检测的完整链路，并给出延迟/吞吐的系统性评估，兼顾方法与工程可部署性。

---

## 六、可行性分析

1. **理论方法成熟**：无监督时序异常检测（AE/LSTM-VAE/Anomaly Transformer）有大量公开实现与基准，理论清晰、可复现；
2. **数据可控可得**：通过仿真生成器可获得带标签数据，公开基准数据集可直接获取，不依赖尚未建成的装置出光；
3. **技术栈成熟**：EPICS、PyTorch、ONNX Runtime、HDF5 均为成熟开源工具，原型系统可实现；
4. **硬件条件**：在线推理原型对 GPU 要求不高，普通单卡即可满足论证需求；
5. **前期基础**：已完成仿真数据生成器（`feldiag`）的开发与验证（含单元测试），数据底座就绪。
