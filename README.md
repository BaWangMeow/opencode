# OpenCode 工作区

这里是 OpenCode 的工作目录，存放笔记、项目、脚本与文档。所有内容都会整理好并同步到 GitHub。

## 目录结构

| 目录 | 用途 |
| :--- | :--- |
| `notes/` | 学习笔记、踩坑记录 |
| `projects/` | 项目代码 |
| `scripts/` | 脚本与工具 |
| `docs/` | 文档 |

## 维护约定

- 每个主题 / 项目使用独立子目录，不混放。
- 新增内容时，在对应目录补一份简短 `README.md` 说明用途。
- 临时文件、依赖、密钥、日志不入库（见 `.gitignore`）。
- 本仓库由 OpenCode 维护，改动会自动提交并推送到 GitHub。
